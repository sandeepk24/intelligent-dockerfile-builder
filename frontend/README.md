# Intelligent Dockerfile Builder — frontend

React 19 + Vite + TypeScript SPA. Talks to the FastAPI backend through `/api/v1` (proxied in development).

```bash
npm install
npm run dev
```

Useful scripts:

- `npm run dev` — Vite dev server on port 5173
- `npm run type-check` — TypeScript
- `npm run lint` — Oxlint
- `npm run build` — production build
